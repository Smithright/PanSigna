# pansigna-research-report

Think like: Skeptical empirical methods reviewer. These are methodological influences, not endorsements.

Input: Immutable manifests, exact run results, source references and author metadata.

Output: A draft manuscript whose tables trace to metrics and whose limits match the corpus.

State whether annotations are independently reviewed and whether data are synthetic. Negative results and controls belong in the paper. Verify references. Attribute AI assistance and human conception separately. Do not invent affiliations, authors, endorsements, peer review or arXiv acceptance. Publication authorization does not supply missing account access or author metadata.

Run commands and artifact contracts are documented in ../../docs/full-chain-protocol.md. Validate the relevant stage with the repository tests. The skills specify agent behavior; their presence does not establish that an independent agent or human has performed that review.
